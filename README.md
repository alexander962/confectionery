# У Катюни

Сайт домашней кондитерской «У Катюни» — авторские торты для праздников и особенных событий.

Проект находится в разработке. Планируются каталог с поиском и фильтрами, выбор начинки и параметров торта, оформление заявки, избранное и личный кабинет. Интерфейс будет адаптирован для компьютеров и телефонов и получит светлую и тёмную темы.

## Технологии

- Next.js 16 и React 19.
- TypeScript.
- App Router: маршруты и общая оболочка в `src/app`.
- SCSS Modules для локальных стилей компонентов.
- ESLint для проверки кода.

## Требования

- Node.js **24.22.2** — версия зафиксирована в `.nvmrc`.
- npm, входящий в состав Node.js.
- Для команд выбора версии Node.js ниже нужен установленный nvm.

## Установка и запуск

Откройте терминал в корне проекта и выполните:

```bash
nvm install
nvm use
npm ci
npm run dev
```

`nvm install` устанавливает версию Node.js из `.nvmrc`, а `nvm use` включает её в текущем терминале. `npm ci` устанавливает зависимости по `package-lock.json`.

После запуска откройте [localhost:3000](http://localhost:3000). Если порт занят, используйте адрес, указанный в терминале. Изменения исходников отображаются автоматически.

Чтобы остановить сервер, нажмите `Ctrl+C`. При работе в новом терминале сначала выполните `nvm use`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run build
```

- `typecheck` — проверка типов без генерации JavaScript-файлов.
- `lint` — проверка правил ESLint.
- `build` — создание production-сборки и проверка возможности собрать приложение.

## Запуск production-сборки

```bash
npm run build
npm run start
```

Перед запуском остановите dev-сервер, если он занимает порт 3000. Команда `start` запускает готовую сборку; после изменения исходников её нужно собрать заново.

## Структура проекта

```text
src/app/           Маршруты, общая оболочка и стили приложения
public/            Статические файлы
next.config.ts     Настройки Next.js
tsconfig.json      Настройки TypeScript
eslint.config.mjs  Настройки ESLint
.nvmrc             Версия Node.js
```

Зависимости (`node_modules`) и результаты сборки (`.next`) создаются локально и не хранятся в Git.
